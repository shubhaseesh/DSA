# Python Concepts - Topic-wise Examples

This folder contains comprehensive Python examples organized by topic to help you understand various Python concepts from basics to advanced topics.

## 📁 File Structure

| File | Topic | Description |
|------|--------|-------------|
| `01_basic_data_types.py` | Data Types | Numbers, strings, booleans, None type with examples |
| `02_data_structures.py` | Data Structures | Lists, tuples, sets, dictionaries with operations |
| `03_control_flow.py` | Control Flow | If-else, loops, break/continue, match-case |
| `04_functions.py` | Functions | Function definitions, arguments, decorators, generators |
| `05_oop.py` | Object-Oriented Programming | Classes, inheritance, properties, special methods |
| `06_exception_handling.py` | Exception Handling | Try-except, custom exceptions, context managers |
| `07_file_io.py` | File I/O | Reading/writing files, CSV, JSON, pathlib |
| `08_modules_packages.py` | Modules & Packages | Creating modules, packages, imports |
| `09_advanced_concepts.py` | Advanced Topics | Decorators, generators, metaclasses, type hints |
| `10_algorithms_data_structures.py` | Algorithms & DS | Sorting, searching, stacks, queues, trees, graphs |

## 🚀 How to Use

1. **Start with Basics**: Begin with files 01-04 if you're new to Python
2. **Progressive Learning**: Each file builds upon previous concepts
3. **Run Examples**: Execute each file to see the concepts in action
4. **Experiment**: Modify the code to understand how things work
5. **Reference**: Use as a quick reference for Python concepts

## 🔍 Quick Reference

### Basic Concepts (Files 01-04)
- **Data Types**: int, float, str, bool, list, tuple, set, dict
- **Control Flow**: if/elif/else, for/while loops, break/continue
- **Functions**: def, *args, **kwargs, lambda, decorators

### Intermediate Concepts (Files 05-07)
- **OOP**: Classes, inheritance, properties, magic methods
- **Error Handling**: try/except/finally, custom exceptions
- **File Operations**: Reading/writing text, CSV, JSON files

### Advanced Concepts (Files 08-10)
- **Modules**: Creating and importing custom modules and packages
- **Advanced Features**: Decorators, generators, context managers, metaclasses
- **Algorithms**: Sorting, searching, and common data structures

## 💡 Learning Tips
